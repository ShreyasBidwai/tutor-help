# Project: TuitionTrack Landing Website

## 1. Brand Identity
- **Name:** TuitionTrack
- **Tagline:** "Better Tracking. Better Learning."
- **Mission:** To streamline tuition management for tutors and enhance learning tracking for students.

### Product Description
TuitionTrack is a comprehensive management platform designed specifically for private tutors and coaching institutes. It bridges the gap between tutors, students, and parents by digitizing the entire tuition management process. The platform offers a seamless experience across Web, Android, and iOS devices, ensuring that critical data is always accessible.

**Core Capabilities:**
- **For Tutors:** Effortless attendance marking, automated fee reminders, homework assignment, and student performance tracking.
- **For Students/Parents:** Real-time visibility into attendance records, fee status, homework updates, and performance analytics.
- **Ecosystem:** A unified database that syncs instantly across the Tutor Web Portal, Tutor Mobile App, and Student Mobile App.

## 2. Design System & Style Guide

### Color Palette
- **Primary Brand Color:** `#4F46E5` (Indigo)
- **Secondary Gradient (Header/Hero):** `linear-gradient(135deg, #4F46E5 0%, #7C3AED 100%)`
- **Background Color:** `#f5f5f5` (Light Grey)
- **Surface/Card Color:** `#FFFFFF` (White)
- **Text Primary:** `#333333`
- **Text Secondary:** `#666666`
- **Text Muted/Legal:** `#999999`
- **Success Green:** `#10B981` / `#D1FAE5` (Background)
- **Error Red:** `#EF4444` / `#FEE2E2` (Background)

### Typography
- **Font Family:** System UI stack (Inter/Roboto preferred if web fonts needed)
  - `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif`
- **Headings:** Bold, often Primary Color (`#4F46E5`)
- **Body:** Clean, legible, 16px base size.

### UI Components
- **Buttons:**
  - Primary: Solid `#4F46E5`, rounded corners (8px), white text.
  - Secondary: Light gray `#E5E7EB`, dark text.
- **Cards:** White background, rounded corners (12px), subtle shadow (`0 2px 8px rgba(0,0,0,0.08)`).
- **Inputs:** Simple borders, focus ring in primary color.
